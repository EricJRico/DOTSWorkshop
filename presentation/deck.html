The one real change

Transform→float3 in an array
A Transform is a class, so no job can hold one. The job moves positions it owns, and the Transforms are set from them afterwards.

The rest are renames

Vector3→float3
Vector3[], float[]→NativeArray<T>
dir.sqrMagnitude→math.lengthsq(dir)
dir.normalized→math.normalize(dir)
Mathf.Clamp→math.clamp
The same maths, written so Burst can compile it.
